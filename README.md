# TSS Drone

## Phase 2-1：基礎理解（Mac・法規制）

ドローンの構造・飛行原理・日本の法規制を整理。  
手を動かす前に、まず全体地図を把握するフェーズ。

---

### 機体構造

| パーツ | 役割 |
|---|---|
| フレーム | 機体の骨格 |
| モーター + ESC | 推力を生む |
| プロペラ | 空気を押し下げる |
| FC（Flight Controller） | 制御の頭脳 |
| バッテリー | 電源 |

---

### 飛行原理

4つのローターの合計推力が機体重量と釣り合うと、  
加速度がゼロになりホバリングが成立する。

| 軸 | 操作内容 |
|---|---|
| Throttle | 4つ全体の推力を増減 |
| Roll | 左右ローター差で横傾き |
| Pitch | 前後ローター差で前後傾き |
| Yaw | 対角ローター差でその場回転 |

---

### 日本の法規制

| 項目 | 内容 |
|---|---|
| 航空法 | 100g以上は機体登録が必要 |
| DIPS2.0 | 国交省の飛行許可申請システム |
| DID | 人口集中地区での飛行制限 |
| 要許可飛行 | 夜間・目視外・第三者上空など |

## Phase 2-2：物理シミュレーション（Mac）

4ローター機の物理モデルをPythonで実装。  
PID制御を3軸へ拡張し、モーター分配まで含めて検証した。

---

### クアッドコプターの物理

4つのモーターを全て同じ方向へ回転させると、  
反トルクによって機体全体がスピンする。

そのため、対角線で逆回転にすることでトルクを相殺し、  
ホバリングを成立させる。

---

### モーター分配式

```text
M1（左前） = throttle + roll - pitch - yaw
M2（右前） = throttle - roll - pitch + yaw
M3（左後） = throttle + roll + pitch + yaw
M4（右後） = throttle - roll + pitch - yaw
```

Roll / Pitch / Yaw の出力を各モーターへ混ぜ込み、  
姿勢制御を実現する。

---

### PIDの3軸拡張

1軸PIDをそのまま3本に拡張し、  
各出力をモーター分配式へ渡す構成。

```python
roll_error      = target_roll - measured_roll
roll_integral   += roll_error * dt
roll_derivative = (roll_error - prev_roll_error) / dt

roll_output = (
    Kp * roll_error
    + Ki * roll_integral
    + Kd * roll_derivative
)
```

---

### 実験結果

t = 3秒時点で roll +15度 の外乱を与え、  
3パターンの挙動を比較した。

| パターン | 挙動 |
|---|---|
| Kpのみ | ゆっくり収束。オーバーシュートなし |
| Ki追加 | 積分ワインドアップが発生し、オフセットが残る |
| Kd追加 | 外乱へ瞬時反応。モーター出力に大きなスパイクが発生 |

---

### PIDの各項が担う役割

Kp・Ki・Kdはそれぞれ異なる役割を持つ。

サスペンションで例えると理解しやすい。

| 項 | 役割 |
|---|---|
| Kp | スプリング。ズレに比例して戻そうとする力 |
| Ki | プリロード調整。長期的なズレを補正 |
| Kd | ダンパー。変化速度に反応して振動を抑制 |

Kiが無い場合、風などの継続外乱に対して  
少し傾いた状態で安定してしまう。

Kdが無い場合、外乱後に振動が残り続ける。

---

### このシミュレーターの限界と意義

このモデルは、

- ドリフト
- 慣性誤差
- モーター遅延
- ノイズ

などを含まない理想モデル。

そのため、Kpのみでも比較的綺麗に収束する。

このフェーズの目的は、

- 3軸PID構造
- モーター分配
- 制御フロー

が正しいかを確認すること。

Ki・Kdの重要性が本格的に現れるのは、  
実機を扱う次フェーズ以降。
